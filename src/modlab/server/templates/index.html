Architecture

What happens when you move a slider

The browser sends the parameters to a JSON endpoint. Flask validates them, runs the computation in Python and returns arrays plus the compute time. Expensive pure results such as eigenbases and fitted models are kept in an in-memory LRU cache, keyed by their inputs. Training that takes longer than a request runs in a background worker that the page polls.

browser ── GET /api/spread/sir?beta=1.7&alpha=0.44 ──▶ Flask
                                                     ├─ validate params (400 on bad input)
                                                     ├─ modlab.spread → modlab.core.ode.rk4
                                                     └─ JSON + meta.compute_ms
browser ── POST /api/jobs {kind: "lstm_trap"} ──────▶ job worker (thread) ─▶ progress ─▶ GET /api/jobs/<id>

Skinning: why dual quaternions keep a twisted arm round

Linear blend skinning averages rotation matrices, which are not rotations, so the mesh collapses where weights mix. Quaternion and dual-quaternion blending keep every vertex transform rigid.
